IndoHiTAB FINAL SAMPLE
======================

This package contains the exact five CSV files supplied as the final Scenario-3 sample, renamed without the browser suffix (1).

Final design verified in indohitab_hitab.ipynb:
- 878 tables
- 2,880 QA pairs
- source table counts: NSF 183, StatCan 339, ToTTo 356
- 8 QA-balanced batches, 360 QA per batch
- 8 pilot tables / 52 pilot QA
- notebook overlap checks report 0 table overlap and 0 QA-ID overlap with IndoHiTab v1

Files:
- tables_sample.csv
- qa_sample.csv
- batches.csv
- pilot_tables.csv
- pilot_qa.csv
- FINAL_SAMPLE_MANIFEST.json
- indohitab_hitab.ipynb (sampling/audit notebook)

The CSV contents were not resampled or altered when packaging.
